# ProLang

This project implements a **Lexical Analyzer** using Lex/Flex as part of a compilation project. It reads source code written in a custom language format and tokenizes it, identifying keywords, identifiers, separators, and operators.

## 📂 Project Structure

- `src/lexical.l`: The Flex source file containing the regular expressions and rules for lexical analysis.
- `src/syntax.y`: The Bison file for syntax analysis.
- `src/source.txt`: The input file where test source code is written.
- `src/commande.bat`: Compilation and execution script.
- *`src/lex.yy.c`*: The C source file automatically generated by Flex.
- *`src/lexical_analyzer`*: The compiled executable file used to run the analyzer.

## ⚙️ Prerequisites

To build and run this project, make sure you have the following installed on your system:
- **Flex** (Fast Lexical Analyzer Generator)
- **GCC** (GNU Compiler Collection)

## 🚀 How to Build and Run

You can automatically build and run the project using the provided script `commande.bat` located in the `src/` directory.

### Option 1: Using the automated script (Linux/macOS)

```bash
cd src
chmod +x commande.bat
./commande.bat
```
*(Alternatively, you can just run `bash commande.bat`)*

### Option 2: Manual Build

If you prefer to compile it manually from the `src/` directory:

1. **Generate the Lexical Analyzer C Code**
   Run Flex on the `.l` specification file:
   ```bash
   flex lexical.l
   ```

2. **Compile the Generated C Code**
   Compile the generated `lex.yy.c` into an executable using GCC:
   ```bash
   gcc lex.yy.c -o lexical_analyzer -lfl
   ```

3. **Run the Analyzer**
   Execute the compiled program and feed it your test input file:
   ```bash
   ./lexical_analyzer < source.txt
   ```

## 📊 Output

The analyzer will tokenize the contents of `source.txt` and print out the recognized tokens (e.g., Keywords, Identifiers, Operators, etc.) to the standard output in the terminal.
