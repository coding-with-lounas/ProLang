Quelques registres les plus utilisés
Les registres sont des emplacements de mémoire très rapides situés directement dans le processeur.
Ils sont utilisés pour stocker temporairement des données ou des résultats d'opérations.
Dans l'assembleur 8086, on distingue plusieurs types de registres :

1.Registres généraux
AX (Accumulateur) : Utilisé pour les calculs.
BX (Base) : utilisé pour accéder à la mémoire
CX (Compteur) : Utilisé comme compteur dans les boucles, par exemple pour répéter une
opération un certain nombre de fois.
DX (Data Extension Register): est un registre polyvalent, mais a un rôle spécial dans les opérations
de multiplication et division.

2. Registres de la pile
SP (Stack Pointer - Pointeur de pile) : Il pointe toujours vers le sommet actuel de la pile. Son contenu est
automatiquement changé par les instructions PUSH et POP.
BP (Base Pointer) : sert de pointeur sur la base de la pile, et permet d’atteindre n’importe quel élément de la
pile (exemple: MOV AX,[BP+2]). Contrairement à SP, BP est souvent manipulé manuellement pour naviguer
dans la pile.

3. Registres de segment
Les registres de segment servent à indiquer au processeur où se trouvent les différentes parties du programme en
mémoire.
DS (Data Segment): Pointe sur le début du segment qui contient les données.
CS (Code Segment): Pointe sur le segment contenant le code du programme.
SS (Stack Segment): segment contenant la pile.
ES (Extra Segment): segment supplémentaire.

Format standard d’une instruction
Les instructions sont les commandes que le processeur exécute. Le format standard d’une instruction est le suivant:

Qu’est-ce qu’un label ?
Les labels (étiquettes) sont des noms donnés à des lignes du programme.
Ils servent de repères pour les instructions de saut (conditionnels ou non) et permettent de pointer vers une
instruction précise.
Exemple :

Qu’est-ce qu’un Mnémonique ?
Il sert à identifier une instruction donnée. Par exemple:
MOV = move (copy)
ADD = addition
JMP = jump
CMP = compare
INT = interrupt

Qu’est-ce qu’un opérande?
Un opérande est une donnée utilisée par une instruction (peut-être un registre, valeur ou mémoire).
En 8086, une instruction peut avoir 0, 1 ou 2 opérandes.

Commentaire
Tout ce qui suit ; sur la même ligne est considéré comme un commentaire.

3. Comparaison
Toutes les comparaisons se font à l'aide de l'instruction CMP
L'instruction CMP (Compare): CMP compare deux opérandes en effectuant une soustraction implicite.

CMP A, B ; Internement fait A - B
Mais le résultat n'est PAS stocké dans A. L'opération sert uniquement à mettre à jour les flags (dans le
registre FLAGS).
Après un CMP, le processeur regarde certains drapeaux (flags) pour décider du saut :
ZF (Zero Flag) : devient 1 si le résultat = 0.
SF (Sign Flag) : indique le signe du résultat (0 = positif, 1 = négatif).
CF (Carry Flag) : Sous-dépassement (A < B), indique une retenue (ou emprunt).
OF (Overflow Flag) : Résultat hors limites.

Trois parties du code assembleur
Un programme assembleur typique est structuré en trois parties : Pile, Données, et code.

1.Segment de pile(Stack Segment)
Qu’est-ce qu’une pile ?
C'est une zone mémoire spéciale utilisée pour sauvegarder temporairement
des données (comme les appels de fonctions et les registres).
Elle fonctionne selon le principe LIFO (Last In, First Out).
Instructions liées à la pile
PUSH registre
Sauvegarde le contenu d’un registre sur la pile.
Exemple: PUSH AX

; Empile le contenu du registre AX

POP registre
Restaure une valeur depuis la pile vers un registre.
Exemple: POP AX ; Dépile contenu du sommet de la pile et le transfère dans
AX

Déclaration d’une pile (Stack Segment)
Avant de pouvoir utiliser les instructions PUSH et POP, il faut :
Réserver un espace mémoire (pile).
Définir un segment de pile grâce à la directive SEGMENT stack.
Initialiser les registres SS (Segment Stack) et SP (Stack Pointer)
Structure de déclaration d'une pile
segment_pile SEGMENT stack
DW 100 DUP (?)
base_pile EQU $

; Début du segment de pile (mot-clé `stack`)

; Réserve 100 mots = 200 octets non initialisés
; Étiquette pour repérer la base de la pile

;(c’est-à-dire l’adresse juste après la fin de la zone réservée)
segment_pile ENDS

; Fin du segment de pile

-> Quand la pile est vide, SP doit pointer sous la zone réservée, c’est-à-dire au "haut" de la pile

→ c’est ce qu’on

appelle ici la base de la pile.
